# Angular

Интерактивный курс по Angular 22 на русском языке: текст урока, редактор кода и живое приложение в одном окне. В ходе курса вы с нуля пишете интернет-магазин настольных игр «Ход конём» — от первой карточки товара до каталога с поиском, корзины, оформления заказа и админки, — а затем разбираетесь, как Angular устроен изнутри, и переносите приложение в настоящий проект Angular CLI.

Для кого: разработчики, которые знают JavaScript/TypeScript и веб, но не работали с Angular.

- Программа курса — [docs/course-plan.md](docs/course-plan.md)
- Статус работ — [docs/roadmap.md](docs/roadmap.md)
- Контекст для разработки — [CLAUDE.md](CLAUDE.md)

Платформа основана на курсе по PixiJS из соседнего репозитория.
