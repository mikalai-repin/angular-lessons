Шаг для проверки того, как платформа показывает ошибки. Попробуйте:

1. В `catalog/catalog.html` замените `[game]` на `[gaem]` — Angular сообщит, что не может привязаться к неизвестному свойству.
2. Замените `<app-game-card` на `<app-game-crad` — неизвестный элемент (NG0304), а NG0303 повторится для каждой карточки: консоль покажет одну строку со счётчиком.
3. В `catalog/catalog.ts` добавьте поле `protected wrong: number = 'строка';` — ошибка TypeScript в консоли с меткой TS, а приложение всё равно запустится.
4. В `app.ts` укажите `templateUrl: './app2.html'` — ошибка с меткой «Сборка»: файл не найден.
