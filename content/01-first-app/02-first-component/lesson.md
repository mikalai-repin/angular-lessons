Начинаем с чистого листа: в шаге всего два файла. Превью пустое, а в консоли ошибка:

```
Error: NG0906: The App is not an Angular component, make sure it has the `@Component` decorator.
```

Angular пытается запустить приложение с классом `App`, но для него это просто класс. Исправим.

## Компонент — класс плюс шаблон

Интерфейс приложения на Angular собирается из **компонентов**. Компонент — это кусок страницы со своей разметкой, стилями и поведением: шапка магазина, карточка игры, корзина. Компоненты вкладываются друг в друга, и вся страница — это дерево компонентов с одним корнем.

Технически компонент — обычный класс TypeScript, к которому добавлены **метаданные**: какой у него шаблон и где на странице он появится. Метаданные задаются **декоратором** `@Component`:

```ts app.ts {1,3-9}
import { Component } from '@angular/core';

@Component({
  selector: 'app-root',
  template: `
    <h1>Ход конём</h1>
    <p>Магазин настольных игр</p>
  `,
})
export class App {}
```

**Декоратор** — функция, которая пишется через `@` прямо перед классом и получает этот класс. `@Component({...})` ничего не меняет в самом классе: он сообщает Angular, что класс — компонент, и сохраняет объект с настройками. Этот объект называется **метаданными** компонента. Декораторы — возможность TypeScript, Angular использует их с самого начала, поэтому в каждом проекте на Angular в `tsconfig.json` включён `experimentalDecorators`.

В метаданных два поля:

- **`selector`** — CSS-селектор, по которому Angular найдёт место для компонента на странице. `'app-root'` означает «элемент `<app-root>`». Компонент вставляет свою разметку внутрь найденного элемента, этот элемент называют **хост-элементом** компонента.
- **`template`** — **шаблон**, разметка компонента. Пока это обычный HTML в строке с обратными кавычками, чтобы писать в несколько строк.

Сам класс пока пустой. Позже в нём появятся данные и методы, которые использует шаблон.

## Откуда берётся `<app-root>`

Элемент `<app-root>` уже есть на странице превью. В настоящем проекте он лежит в файле `src/index.html`, который создаёт Angular CLI:

```html index.html
<body>
  <app-root></app-root>
</body>
```

Всё остальное содержимое страницы рисует Angular.

Префикс `app-` в селекторе — соглашение: с ним имена компонентов не совпадут ни с обычными тегами HTML (`<header>`, `<main>`), ни с будущими. Angular CLI по умолчанию добавляет `app-` ко всем компонентам проекта.

::: task
Превратите класс `App` в компонент: добавьте декоратор `@Component` с селектором `app-root` и шаблоном из заголовка «Ход конём» и абзаца «Магазин настольных игр». `Component` уже импортирован из `@angular/core`.
:::

## Что получилось

В превью появились заголовок и абзац, а ошибка из консоли исчезла. Осталась строка `Angular is running in development mode.` — Angular сообщает, что работает в **режиме разработки**: с дополнительными проверками и подробными сообщениями об ошибках. В продакшен-сборке этих проверок нет, и приложение работает быстрее.

Поэкспериментируйте:

- поменяйте текст в шаблоне — превью обновится через секунду;
- уберите строку `selector: 'app-root',` — у компонента без селектора Angular использует селектор по умолчанию `ng-component`, не находит такой элемент на странице и сообщает об этом в консоли: `NG05104: The selector "ng-component" did not match any elements`. Верните селектор.

::: tip
Обратите внимание: класс называется `App`, а не `AppComponent`. Так называет корневой компонент Angular CLI в новых проектах, и файлы тоже называются коротко: `app.ts`, а не `app.component.ts`. В старых проектах вы встретите длинные имена — это то же самое.
:::

::: legacy Вы встретите в старом коде: NgModule и standalone
До Angular 14 компонент нельзя было использовать сам по себе: его объявляли в модуле.

```ts
@NgModule({
  declarations: [AppComponent],
  imports: [BrowserModule],
  bootstrap: [AppComponent],
})
export class AppModule {}
```

Потом появились **standalone-компоненты** — самостоятельные, без модулей, — и с Angular 19 все компоненты такие по умолчанию. Если в старом коде вы видите `standalone: true` в `@Component`, это та же самая настройка, просто записанная явно.
:::
