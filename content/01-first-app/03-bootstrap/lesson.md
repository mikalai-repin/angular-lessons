Компонент мы описали, но сам по себе он ничего не делает: это класс с метаданными. Кто-то должен создать его, найти на странице `<app-root>` и вставить туда шаблон. Этим занимается файл `main.ts`.

## Точка входа

```ts main.ts
import { bootstrapApplication } from '@angular/platform-browser';
import { App } from './app';

bootstrapApplication(App).catch((err) => console.error(err));
```

`main.ts` — **точка входа**: первый файл, который выполняет браузер. Такой же `main.ts` создаёт Angular CLI в новом проекте.

`bootstrapApplication(App)` — **запуск приложения** с корневым компонентом `App`. За этой одной строкой стоит довольно много работы:

1. Angular создаёт приложение и его общие службы: например, механизм, который обновляет страницу при изменении данных.
2. Получает описание компонента: в превью здесь срабатывает JIT-компилятор и превращает шаблон в код.
3. Ищет на странице элемент по селектору `app-root`.
4. Создаёт экземпляр класса `App` — обычный `new App()`, только руками Angular.
5. Отрисовывает шаблон внутрь `<app-root>`.

Функция асинхронная и возвращает `Promise`. Если на одном из шагов что-то пошло не так, промис отклоняется, и `.catch` выводит ошибку в консоль.

`@angular/platform-browser` в названии пакета — не случайность: «платформа» здесь — браузер. Angular умеет работать и на сервере (серверный рендеринг), и тогда приложение запускается другой функцией. До этого мы дойдём в части 3.

## Что возвращает запуск

Промис из `bootstrapApplication` разрешается объектом `ApplicationRef` — ссылкой на запущенное приложение. Через неё можно узнать, например, какие корневые компоненты созданы:

```ts main.ts {4-5}
import { bootstrapApplication } from '@angular/platform-browser';
import { App } from './app';

bootstrapApplication(App)
  .then((appRef) => console.log('Магазин запущен. Корневых компонентов:', appRef.components.length))
  .catch((err) => console.error(err));
```

В обычном приложении `ApplicationRef` нужен редко. Но `.then` показывает важную вещь: код после запуска выполняется, когда компонент уже создан и отрисован.

::: task
Добавьте в `main.ts` вывод в консоль после успешного запуска: «Магазин запущен. Корневых компонентов:» и число из `appRef.components.length`.
:::

## Что получилось

В консоли появилась строка `Магазин запущен. Корневых компонентов: 1`. Корневой компонент у нас один — `App`, и обычно так и бывает: всё остальное приложение будет вложено в него.

::: tip
Обратите внимание на подсказки редактора: наведите курсор на `appRef` — редактор знает, что это `ApplicationRef`, и после точки предложит его свойства. Типы Angular — одна из причин, почему он написан на TypeScript.
:::

## Эксперимент: селектор не найден

В `app.ts` замените селектор `'app-root'` на `'app-shop'`. В консоли появятся две похожие ошибки:

```
ERROR RuntimeError: NG05104: The selector "app-shop" did not match any elements. Find more at https://v22.angular.dev/errors/NG05104
RuntimeError: NG05104: The selector "app-shop" did not match any elements. Find more at https://v22.angular.dev/errors/NG05104
```

На странице нет элемента `<app-shop>`, поэтому шаг 3 из списка выше не удался. Ошибка одна, а сообщений два:

- первое, с пометкой `ERROR`, выводит сам Angular — его встроенный обработчик ошибок;
- второе выводит наш `.catch` в `main.ts`, потому что промис запуска отклонён.

У каждой ошибки Angular есть код вида `NG05104` и страница с объяснением на angular.dev — в консоли код и адрес становятся ссылками. Верните селектор `'app-root'`.

::: deep Под капотом: что Angular делает с хост-элементом
Откройте в браузере инструменты разработчика (F12), вкладку Elements, и найдите `<app-root>` внутри iframe превью. У элемента появился атрибут:

```html
<app-root ng-version="22.2.1">
```

Его добавляет Angular при запуске корневого компонента. По этому атрибуту отладочные инструменты находят приложения Angular на странице — сам Angular в режиме разработки ищет их запросом `document.querySelectorAll('[ng-version]')`.

И ещё одна проверка порядка событий. Если сразу после вызова `bootstrapApplication(App)` поискать `document.querySelector('h1')`, заголовка ещё не будет: запуск асинхронный. А внутри `.then` он уже на месте.
:::
