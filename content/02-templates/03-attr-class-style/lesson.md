У карточки появятся рейтинг из пяти звёзд и особый вид для игры, которой нет в наличии. Для этого нужны три разновидности привязок: к атрибуту, к CSS-классу и к стилю.

## Привязка атрибута

Не у каждого атрибута HTML есть свойство DOM. Например, у атрибутов `data-*`: напишите `<p [data-id]="title">` — и получите знакомую ошибку `NG0303: Can't bind to 'data-id' since it isn't a known property of 'p'`. Для таких случаев есть **привязка атрибута** (attribute binding) — префикс `attr.`:

```html
<p [attr.data-id]="title">…</p>
```

Она пишет прямо в атрибут элемента, через `setAttribute`. Если значение выражения `null` или `undefined`, Angular удалит атрибут совсем.

Чаще всего `attr.` встречается с атрибутами доступности ARIA. Рейтинг у нас — пять звёзд, нарисованных CSS. Человек видит «четыре с половиной звезды», а программа чтения с экрана — пустой элемент. Опишем его словами:

```html app.html {1}
<span class="rating" role="img" [attr.aria-label]="'Рейтинг: ' + rating + ' из 5'">
  <span class="stars" [style.width.%]="(rating / 5) * 100"></span>
</span>
```

`role="img"` говорит, что элемент — картинка, а `aria-label` — её текстовое описание: «Рейтинг: 4.6 из 5».

::: tip
Для атрибутов `aria-*` Angular 22 понимает и короткую запись: `[aria-label]="…"` тоже запишет атрибут — мы проверили. Но запись `[attr.aria-label]` вы встретите чаще, и она работает в любой версии.
:::

## Привязка стиля

Как нарисованы звёзды: серые `★★★★★`, а поверх — такие же жёлтые в элементе `.stars`, обрезанном по ширине (стили — в `app.css`). Ширину задаёт **привязка стиля** (style binding):

```html
<span class="stars" [style.width.%]="(rating / 5) * 100"></span>
```

`[style.width]` — свойство CSS `width`, а `.%` — единица измерения, которую Angular допишет к числу. При рейтинге 4.6 получится `width: 92%`. Можно писать и другие единицы: `[style.width.px]="120"`, `[style.font-size.em]="1.2"`. Без единицы значение должно быть готовой строкой: `[style.color]="'red'"`.

## Привязка класса

Для игры, которой нет в наличии, карточка должна стать серой. В `app.css` уже есть правила для класса `.sold-out`. Осталось добавлять класс, когда товара нет:

```html app.html {1}
<article class="card" [class.sold-out]="inStock === 0">
```

`[class.sold-out]` — **привязка класса** (class binding): если выражение истинно, у элемента появляется класс `sold-out`, если ложно — исчезает. Статический `class="card"` остаётся на месте: Angular не перезаписывает весь атрибут, а добавляет и убирает один класс.

```ts app.ts {5}
protected readonly title = 'Остров сокровищ';
protected readonly price = 1990;
protected readonly cover = '/assets/covers/treasure-island.svg';
protected readonly inStock: number = 12;
protected readonly rating = 4.6;
```

::: task
1. Добавьте поле `rating = 4.6`.
2. Между названием и ценой вставьте разметку рейтинга из примера выше.
3. Добавьте `<article>` привязку `[class.sold-out]="inStock === 0"`.
:::

## Что получилось

Под названием появились звёзды: четыре жёлтые и почти целая пятая. Поставьте `inStock = 0`: обложка станет серой, цена — бледной, кнопка — неактивной. Верните `12`.

Посмотрите на карточку во вкладке Elements инструментов разработчика: у `<span class="rating">` есть атрибут `aria-label="Рейтинг: 4.6 из 5"`, а у `.stars` — `style="width: 92%;"`.

## Много классов и стилей сразу

Есть и групповые формы — без имени после точки:

```html
<p class="card" [class]="{ featured: true, 'sold-out': inStock === 0 }"></p>
<p class="card" [class]="'featured new'"></p>
<p [style]="{ opacity: 0.5, 'font-size': '14px' }"></p>
```

`[class]` принимает строку с классами через пробел, массив или объект «класс → условие». Мы проверили: статический `class="card"` при этом сохраняется. `[style]` принимает строку или объект «свойство → значение».

На практике удобнее и понятнее отдельные привязки `[class.x]` и `[style.x]`: каждая отвечает за одну вещь.

::: legacy Вы встретите в старом коде: ngClass и ngStyle
```html
<article [ngClass]="{ 'sold-out': inStock === 0 }" [ngStyle]="{ width: '92%' }">
```
Это директивы из `@angular/common`, их нужно было подключать в `imports` компонента. Сейчас то же самое делают встроенные привязки `[class]` и `[style]`, и руководство по стилю Angular советует именно их: они проще и не требуют импортов.
:::
