У «Острова сокровищ» скидка: раньше он стоил 2490 ₽. Покажем старую цену зачёркнутой и бейдж «−20 %». Процент скидки — это выражение `((1 - price / oldPrice) * 100).toFixed(0)`: длинное, и его хочется как-то назвать. А ещё в шаблоне дважды повторяется `inStock === 0`. Для таких случаев в шаблонах есть переменные.

## `@let`

```html app.html {1-2,4,11-12,14}
@let soldOut = inStock === 0;
@let discount = ((1 - price / oldPrice) * 100).toFixed(0);

<article class="card" [class.sold-out]="soldOut">
  <img class="cover" [src]="cover" [alt]="title" />
  <div class="body">
    <h2 class="title">{{ title }}</h2>
    <!-- …рейтинг… -->
    <p class="price">
      {{ price }} ₽
      <s class="old-price">{{ oldPrice }} ₽</s>
      <span class="badge">−{{ discount }} %</span>
    </p>
    <button class="button" [disabled]="soldOut" (click)="addToCart()">В корзину</button>
  </div>
</article>
```

```ts app.ts {3}
protected readonly title = 'Остров сокровищ';
protected readonly price = 1990;
protected readonly oldPrice = 2490;
```

`@let имя = выражение;` объявляет **переменную шаблона** (template variable). Справа — обычное выражение шаблона, и, как любая привязка, оно пересчитывается, когда Angular перепроверяет шаблон. Точка с запятой в конце обязательна, без неё компилятор сообщит:

```
Incomplete @let declaration "soldOut". @let declarations must be written as `@let <name> = <value>;`
```

Обратите внимание на `toFixed(0)`: округлить через `Math.round` в шаблоне нельзя — `Math` шаблону не виден (помните первый шаг?). А метод числа `toFixed` — можно.

Теперь условие «нет в наличии» записано один раз и названо по смыслу: `[class.sold-out]="soldOut"`, `[disabled]="soldOut"`. Если правило поменяется (скажем, «нет в наличии, если осталось меньше двух»), править придётся одно место.

::: task
1. Добавьте поле `oldPrice = 2490`.
2. В начале карточки объявите `@let soldOut` и `@let discount`, как в примере.
3. Замените оба `inStock === 0` на `soldOut`.
4. Замените абзац с ценой на вариант со старой ценой и бейджем.
:::

## Что получилось

Рядом с ценой появились зачёркнутые `2490 ₽` и красный бейдж `−20 %`. Карточка ведёт себя как раньше: проверьте с `inStock = 0`.

## Правила `@let`

Переменная шаблона — константа. Её нельзя переприсвоить, нельзя читать до объявления и нельзя объявить второй раз с тем же именем. Видна она от места объявления до конца шаблона, включая вложенные элементы.

Здесь превью и настоящий проект расходятся, и это важно знать. JIT-компилятор в превью **не проверяет** эти правила: напишите `(click)="soldOut = true"` или перенесите `{{ discount }}` выше объявления — ошибки не будет, просто код не сработает как ожидается. А AOT-компилятор с проверкой шаблонов остановит сборку. Мы проверили все три случая:

```
error NG8015: Cannot assign to @let declaration 'soldOut'.
error NG8016: Cannot read @let declaration 'discount' before it has been defined.
error NG8017: Cannot declare @let called 'soldOut' as there is another symbol in the template with the same name.
```

::: tip
`@let` удобен для коротких выражений, которые нужны в шаблоне несколько раз или которым полезно дать имя. Сложные вычисления по-прежнему лучше держать в классе: в следующей главе для этого появится `computed`.
:::

::: deep Под капотом: во что превращается `@let`
В последнем шаге главы мы увидим скомпилированный шаблон. Забегая вперёд: наши `@let` превратятся в обычные константы JavaScript внутри функции шаблона — `const soldOut_r3 = ctx.inStock === 0;`. Никакой «магии» и никаких затрат сверх вычисления самого выражения.
:::
