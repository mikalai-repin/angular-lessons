Эффект пишет в консоль список корзины. Для аналитики полезно знать ещё и то, какую игру покупатель смотрел, когда менял корзину. Добавим в сообщение название открытой игры — и наткнёмся на тонкость, о которой нужно знать каждому, кто пишет эффекты.

## Лишняя зависимость

Самое очевидное решение — прочитать `game()` в эффекте:

```ts app.ts {3}
effect(() => {
  const summary = this.cartSummary() || 'пусто';
  console.log(`Корзина: ${summary} (на экране — ${this.game().title})`);
});
```

Попробуйте и полистайте игры, ничего не добавляя в корзину. Консоль заполняется строками:

```
Корзина: пусто (на экране — Остров сокровищ)
Корзина: пусто (на экране — Драконья почта)
Корзина: пусто (на экране — Зельевары)
```

Корзина не менялась, а эффект срабатывает. Причина — правило, которое вы уже знаете: эффект зависит от **всего**, что прочитал. Он прочитал `game()`, значит, перезапускается при каждой смене игры. Для эффекта нет разницы между «главным» сигналом и сигналом, прочитанным мимоходом.

## `untracked`

Функция `untracked` выполняет код и **не** записывает прочитанные в нём сигналы в зависимости:

```ts app.ts {1,7-8}
import { Component, computed, effect, signal, untracked } from '@angular/core';

// …

effect(() => {
  const summary = this.cartSummary() || 'пусто';
  // Открытая игра нужна для сообщения, но её смена — не повод его повторять
  const title = untracked(() => this.game().title);
  console.log(`Корзина: ${summary} (на экране — ${title})`);
});
```

Теперь эффект зависит только от `cartSummary`. `game()` он по-прежнему читает и получает актуальное значение, но не подписывается на него.

Код, где Angular записывает прочитанные сигналы в зависимости, называется **реактивным контекстом** (reactive context): функция `computed`, функция эффекта, шаблон. `untracked` временно выключает запись зависимостей внутри реактивного контекста.

::: task
1. Импортируйте `untracked`.
2. Добавьте в сообщение эффекта название открытой игры, прочитанное через `untracked`, как в коде выше.
3. Полистайте игры — новых строк в консоли нет. Добавьте игру в корзину — строка появилась, и в ней название открытой игры.
:::

## Что получилось

Эффект срабатывает только при изменении корзины, а в сообщении — игра, которая была на экране в этот момент:

```
Корзина: пусто (на экране — Остров сокровищ)
Корзина: Зельевары × 1 (на экране — Зельевары)
```

Для эксперимента уберите `untracked`: напишите `const title = this.game().title;` и снова полистайте игры. Строки вернулись. Верните `untracked`.

## Где `untracked` нужен на практике

Чаще всего — когда эффект вызывает **чужой код**. Представьте, что вместо `console.log` эффект вызывает метод сервиса аналитики: `this.analytics.track(...)`. Вы не знаете, какие сигналы этот метод читает внутри, например текущего пользователя или язык интерфейса. Каждый такой сигнал незаметно станет зависимостью вашего эффекта. Защита — вызывать чужой код внутри `untracked`:

```ts
effect(() => {
  const summary = this.cartSummary();
  untracked(() => this.analytics.track('cart-changed', summary));
});
```

Зависимости эффекта видны в первых строках, а всё остальное от них не зависит.

::: warning
`untracked` не делает чтение «устаревшим»: внутри вы получаете текущее значение сигнала. Он только решает, будет ли перезапуск, если этот сигнал изменится.
:::
