Поле поиска со второй главы только пишет запрос в консоль. Пора сделать настоящий поиск: каталог показывает только подходящие игры и обновляется на каждую букву. А если не подошло ничего — пишет «Ничего не найдено». Для последнего у `@for` есть блок `@empty`.

## Запрос — сигнал, каталог — вычисляемый

Строка поиска — состояние, которое меняет пользователь, значит, изменяемый сигнал. А список видимых игр из неё вычисляется:

```ts app.ts
// Строка поиска и игры, которые ей подходят
protected readonly query = signal('');
protected readonly visibleGames = computed(() => {
  const query = this.query().trim().toLowerCase();
  return GAMES.filter((game) => game.title.toLowerCase().includes(query) || game.tags.some((tag) => tag.includes(query)));
});
```

Ищем по названию и по тегам: у шахмат, го и нард есть тег «классика». Пустой запрос подходит ко всем играм: любая строка «содержит» пустую.

Поле `games` больше не нужно: каталог берёт игры из `visibleGames()`. Метод `search` тоже: вместо поиска по Enter — запись запроса в сигнал при каждом вводе:

```html app.html
<input #searchBox class="search" type="search" placeholder="Найти игру" (input)="query.set(searchBox.value)" />
```

Абзац «Ищем: …» под полем удалите: теперь ответ на запрос — сам каталог.

## `@empty`

```html app.html {3-5}
@for (game of visibleGames(); track game.id) {
  <!-- … плитка … -->
} @empty {
  <p class="empty muted">Ничего не найдено по запросу «{{ query() }}»</p>
}
```

Блок `@empty` идёт сразу после `@for` и показывается, когда в массиве нет ни одного элемента. Без него пришлось бы писать отдельный `@if (visibleGames().length === 0)` и следить, чтобы условие совпадало с тем, что перебирает `@for`.

Абзац — внутри сетки `.grid`, поэтому у класса `empty` в `app.css` есть `grid-column: 1 / -1`: растянуться на все колонки.

::: task
1. Добавьте сигнал `query` и вычисляемый сигнал `visibleGames`, удалите поле `games` и метод `search`.
2. В поле поиска замените `(keydown.enter)` на `(input)="query.set(searchBox.value)"`. Абзац «Ищем» удалите.
3. Перебирайте в каталоге `visibleGames()` и добавьте `@empty` с текстом «Ничего не найдено по запросу «…»».
:::

## Что получилось

Наберите «шах» — осталась одна плитка, «Шахматы «Классика»». Сотрите и наберите «классика» — три игры: шахматы, го и нарды, найденные по тегу. Наберите «монополия» — вместо плиток «Ничего не найдено по запросу «монополия»».

Каталог меняется на каждую букву. Помните загадку из главы 2, когда абзац «Ищем» не обновлялся при наборе? Тогда в поле не было обработчика `(input)`, и Angular не знал, что что-то изменилось. Теперь обработчик записывает текст в сигнал, а от сигнала зависит `visibleGames`, от него — шаблон.

Корзина живёт отдельно от поиска: добавьте игру, найдите другую — позиции в корзине на месте.

::: tip
Поиск на каждую букву по двенадцати играм в памяти — мгновенный. Когда игры будут приходить с сервера (глава 11), запрос на каждую букву станет расточительным, и мы научимся ждать паузу в наборе.
:::
