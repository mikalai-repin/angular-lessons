Заказ можно забрать в магазине или получить с курьером. Для самовывоза адрес не нужен, для курьера — обязателен. А раз курьер должен дозвониться, без телефона нельзя. Поля и правила формы зависят от того, что покупатель выбрал в другом поле.

## Что изменилось в коде

- В модели появилась группа `delivery`: способ (`method`: `'pickup'` или `'courier'`), адрес и флажок `callBefore` — «позвонить за час до приезда». Начальный способ — самовывоз.
- В шаблоне — группа «Доставка»: два переключателя, поле адреса и флажок. С переключателями и флажками `[formField]` работает так же, как с текстом: у каждого переключателя свой `value`, а поле формы хранит значение выбранного; у флажка значение — `true` или `false`.
- «К оплате» теперь считает `computed` `toPay`: при самовывозе плата за доставку не нужна. Он читает сигнал значения поля — `this.checkoutForm.delivery.method().value()` — и пересчитывается, когда покупатель переключает способ.

Пока адрес и флажок видны всегда и ничем не проверяются — это и исправим.

## Скрытые поля

Правило `hidden` скрывает поле, пока условие истинно:

```ts checkout/checkout.ts
const delivery = checkout.delivery;
// Самовывоз: адрес и звонок не нужны. Скрытое поле не проверяется и не влияет на форму
hidden(delivery.address, {
  when: ({ valueOf }) => valueOf(delivery.method) === 'pickup',
});
hidden(delivery.callBefore, {
  when: ({ valueOf }) => valueOf(delivery.method) === 'pickup',
});
```

`when` — функция с тем же контекстом, что у `validate`, и пересчитывается так же: зависит от того, что прочитала.

Что значит «скрыто» для формы:

- правила проверки скрытого поля **не выполняются** — даже `required` не даст ошибки;
- скрытое поле не влияет на состояние родителя: форма может быть верной, хотя скрытый адрес пуст.

Но из DOM поле `hidden` **не убирает** — это ваша работа. Состояние поля сообщает, скрыто ли оно, а шаблон решает, что показывать:

```html checkout/checkout.html
<!-- Скрытое поле убираем из DOM сами: hidden только сообщает, что поле скрыто -->
@if (!checkoutForm.delivery.address().hidden()) {
  <label class="field">
    Адрес
    <input
      autocomplete="street-address"
      [formField]="checkoutForm.delivery.address"
    />
    <app-field-errors [field]="checkoutForm.delivery.address" />
  </label>
}
```

Почему так, а не «Angular спрячет сам»? Спрятать можно по-разному: убрать из DOM, свернуть с анимацией, показать серым с подсказкой. Форма отвечает за данные и правила, а как выглядит страница — решает шаблон.

## Правила при условии

Для курьера нужны три правила сразу: адрес обязателен, в нём хотя бы 10 символов, и телефон тоже обязателен. Группу правил, которые действуют при условии, задаёт `applyWhen`:

```ts checkout/checkout.ts
// Правила курьерской доставки — группой, пока выбран курьер
applyWhen(
  checkout,
  ({ value }) => value().delivery.method === 'courier',
  (order) => {
    required(order.delivery.address, { message: 'Куда привезти заказ?' });
    minLength(order.delivery.address, 10, {
      message: 'Укажите улицу, дом и квартиру',
    });
    required(order.contacts.phone, { message: 'Курьеру нужен ваш телефон' });
  },
);
```

Аргументы: путь, к которому применяются правила (здесь — вся форма), условие и функция схемы. Пока условие ложно, правил из этой функции как будто нет.

Правила адреса можно было бы написать и без `applyWhen`: скрытый при самовывозе адрес и так не проверяется. А вот телефон не скрыт никогда — для него условие нужно обязательно. Собрать все «курьерские» правила в одном месте — ещё и читаемее.

::: tip
Для одного правила хватит настройки `when`, она есть у всех встроенных правил: `required(contacts.phone, { when: ({ valueOf }) => valueOf(delivery.method) === 'courier' })`.
:::

## Отключённые поля

Флажок «Позвонить за час» бессмыслен без телефона. Скрывать его не хочется: пусть покупатель видит, что такая возможность есть, и знает, что для неё нужно. Это **отключённое поле**:

```ts checkout/checkout.ts
// Позвонить можно, только если есть номер. Строка — причина, её увидит покупатель
disabled(delivery.callBefore, {
  when: ({ valueOf }) =>
    !valueOf(contacts.phone).trim() &&
    'Укажите телефон, и курьер позвонит заранее',
});
```

`when` у `disabled` может вернуть `true`/`false` или строку — **причину отключения**. `[formField]` ставит элементу атрибут `disabled`, а причины лежат в состоянии поля — `disabledReasons()`, массив объектов с `message`:

```html checkout/checkout.html
@for (
  reason of checkoutForm.delivery.callBefore().disabledReasons();
  track reason.message
) {
  <span class="muted">{{ reason.message }}</span>
}
```

Отключённое поле, как и скрытое, не проверяется и не влияет на «тронуто» и «изменено» у родителя. Значение в модели остаётся: если флажок успели отметить, а потом стёрли телефон, в модели будет `callBefore: true`.

::: task
1. Скройте адрес и флажок звонка, пока выбран самовывоз (`hidden`), а в шаблоне выводите их только когда они не скрыты (`@if`).
2. Правила курьерской доставки — через `applyWhen`: адрес обязателен («Куда привезти заказ?») и не короче 10 символов («Укажите улицу, дом и квартиру»), телефон обязателен («Курьеру нужен ваш телефон»).
3. Флажок звонка отключён, пока телефон пуст, с причиной «Укажите телефон, и курьер позвонит заранее». Выведите причины под флажком.
:::

## Что получилось

При самовывозе в группе «Доставка» только переключатели, «к оплате» — без доставки. Выберите «Курьером» — появились адрес и серый флажок с подсказкой «Укажите телефон…», а «к оплате» выросла на стоимость доставки. Напечатайте в адресе «Ленина» и уйдите из поля — «Укажите улицу, дом и квартиру». Введите телефон — флажок стал активным, подсказка исчезла.

Вернитесь к самовывозу: адрес и флажок пропали вместе с ошибкой. Снова «Курьером» — адрес на месте, «Ленина» никуда не делась: значение живёт в модели, а `@if` убирал только элемент.

## Эксперименты

**Скрытое поле на странице.** Уберите `@if` вокруг адреса. Поле видно и при самовывозе, а в консоли предупреждение:

```text
NG01916: Field 'delivery.address' is hidden but is being rendered. Hidden fields should be removed from the DOM using @if.
```

Angular замечает, что `[formField]` связан со скрытым полем, и подсказывает, что вы забыли `@if`. Верните его.

**Скрытое не проверяется.** Добавьте перед `applyWhen` правило без всякого условия: `required(delivery.address, { message: 'Адрес нужен всегда' })`. Выберите «Курьером» и уйдите из пустого адреса — под ним две ошибки: «Адрес нужен всегда» и «Куда привезти заказ?». Переключитесь на самовывоз: адрес скрыт, и ошибок нет, хотя новое правило действует всегда, — скрытое поле не проверяется. Уберите правило.

::: deep Под капотом: «неинтерактивное» поле
В состоянии поля есть вычисляемый сигнал «поле неинтерактивно»: оно скрыто, отключено или только для чтения (правило `readonly`). Проверки такого поля Angular пропускает целиком — ошибки пусты, — а родитель не учитывает его «тронуто» и «изменено». Все три сигнала наследуются: если скрыта группа `delivery`, скрыты и все её поля.
:::
