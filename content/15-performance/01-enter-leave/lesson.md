Магазин умеет всё, что нужно покупателю: каталог, страница игры, корзина, оформление заказа, вход. В этой главе он станет живее и быстрее. Мы добавим анимации, которые помогают понять, что произошло, и сделаем так, чтобы страница не тратила время на то, чего покупатель ещё не видит.

К концу главы у магазина появятся:

- строки корзины, которые плавно въезжают и уезжают, а не исчезают рывком;
- отзывы на странице игры, которые загружаются, только когда покупатель открыл вкладку «Отзывы»;
- обложки, которые браузер грузит в правильном порядке: главная картинка экрана — первой, остальные — без спешки;
- обложка, которая после «В корзину» летит из карточки в корзину в шапке.

Попутно разберём, что делает список тяжёлым и как Angular откладывает загрузку кода.

## Что изменилось в коде

Код — решение практикума главы 14 и одна «закадровая» правка. В `cart/cart-page/cart-page.css` появились готовые стили анимации строк корзины — курс не про CSS:

```css cart/cart-page/cart-page.css
.row-enter {
  animation: row-in 0.3s ease-out;
}
@keyframes row-in {
  from {
    opacity: 0;
    transform: translateX(-24px);
  }
}

.row-leave {
  animation: row-out 0.3s ease-in forwards;
}
@keyframes row-out {
  to {
    opacity: 0;
    transform: translateX(24px);
  }
}
```

Класс `row-enter` запускает анимацию «въехать слева и проявиться», `row-leave` — «уехать вправо и растаять». `forwards` оставляет строку в последнем кадре — прозрачной. Ниже в файле есть ещё медиазапрос `prefers-reduced-motion` — о нём в конце шага.

## Почему исчезновение не анимируется само

Положите в корзину пару игр и откройте её. Нажмите `×` у первой строки: она пропадает мгновенно, а строки ниже прыгают вверх. Глаз не успевает понять, что случилось.

Добавить анимацию появления несложно и без Angular: класс с `animation` на элементе сработает, как только элемент окажется в DOM. С исчезновением так не выйдет. `@for` увидел, что позиции больше нет, и удалил её элемент из DOM сразу. Анимировать уже нечего.

Значит, кто-то должен **задержать удаление**: сначала проиграть анимацию, потом убрать элемент. Этим и занимается Angular, если попросить.

## `animate.enter` и `animate.leave`

Два специальных атрибута шаблона:

```html cart/cart-page/cart-page.html {5-6}
@for (item of cart.items(); track item.game.id) {
  <div
    class="cart-row"
    [class.even]="$even"
    animate.enter="row-enter"
    animate.leave="row-leave"
  >
    …
  </div>
}
```

- **`animate.enter="row-enter"`** — когда элемент появился в DOM, Angular добавляет ему класс `row-enter`. CSS запускает анимацию. Когда она закончилась (события `animationend` или `transitionend`), Angular убирает класс.
- **`animate.leave="row-leave"`** — когда элемент пора удалить, Angular **сначала** добавляет класс `row-leave` и ждёт конца анимации. Удаляет элемент только потом.

Как долго ждать, Angular узнаёт у браузера. Он смотрит, какие анимации и переходы запустил класс, и ждёт самую длинную. Длительность в шаблоне не пишут — она живёт в CSS.

Атрибуты работают на любом элементе, который шаблон создаёт и удаляет: на строке `@for`, на содержимом `@if`.

::: task
В `cart-page.html` добавьте строке корзины (`<div class="cart-row">`) атрибуты `animate.enter="row-enter"` и `animate.leave="row-leave"`.
:::

## Что получилось

Откройте корзину с двумя-тремя играми. Строки въезжают слева — анимация появления срабатывает и тогда, когда строки создаются вместе со страницей. Нажмите `×`: строка уезжает вправо и тает, и только потом строки ниже поднимаются.

Присмотритесь к номерам, пока строка уезжает. Оставшиеся строки уже перенумерованы, а у уходящей — старый номер. Для Angular её позиции больше нет: элемент отцеплен от шаблона, привязки в нём больше не обновляются. Он лишь доживает в DOM до конца анимации.

Нажмите «Очистить корзину». Все строки уезжают одновременно, и только потом появляется «Корзина пуста». Удаляется весь блок `@if` со строками, и Angular ждёт анимации исчезновения внутри него.

## Эксперименты

**Класс без стилей.** Замените `animate.leave="row-leave"` на `animate.leave="row-gone"` — такого правила в CSS нет. Нажмите `×`: строка исчезает мгновенно, как раньше. Angular добавил класс, не нашёл анимации и удалил элемент в следующем кадре. Ошибки нет: «анимации нет» — нормальный случай. Если анимация не играет, первым делом проверьте имя класса. Верните `row-leave`.

**Переход вместо анимации.** Анимация исчезновения работает и с CSS-переходом (`transition`). Замените правило `.row-leave`:

```css
.row-leave {
  opacity: 0;
  transition: opacity 0.3s;
}
```

Теперь строка только тает, без сдвига. Для появления переходу нужна начальная точка: элемент только что создан, «переходить» ему не из чего. Её задаёт правило `@starting-style`:

```css
.row-enter {
  transition: opacity 0.3s;
  @starting-style {
    opacity: 0;
  }
}
```

Верните оба правила к анимациям `@keyframes`.

**Меньше движения.** Некоторых людей движение на экране утомляет или укачивает. В системе можно попросить «уменьшить движение», и сайт узнаёт об этом из медиазапроса `prefers-reduced-motion`. Angular сам эту настройку не проверяет. Поэтому в `cart-page.css` есть правило, которое выключает анимации:

```css
@media (prefers-reduced-motion: reduce) {
  .row-enter,
  .row-leave {
    animation: none;
  }
}
```

Включить настройку можно без перенастройки системы. В Chrome откройте DevTools → меню «⋮» → More tools → Rendering → «Emulate CSS media feature prefers-reduced-motion» → `reduce`. Перезапустите превью: строки появляются и исчезают сразу. Анимации у класса нет — значит, ждать нечего, как в первом опыте.

## Как в настоящем проекте

Так же, как в превью: компилятор превращает атрибуты в инструкции `ɵɵanimateEnter("row-enter")` и `ɵɵanimateLeave("row-leave")`, и в AOT, и в JIT. Подключать ничего не нужно: анимации появления и исчезновения — часть `@angular/core`.

::: legacy Вы встретите в старом коде: @angular/animations
До Angular 20.2 анимации описывали в TypeScript отдельным пакетом `@angular/animations`: триггер с состояниями и переходами, привязанный к элементу через `@`:

```ts
@Component({
  animations: [
    trigger('row', [
      transition(':enter', [
        style({ opacity: 0 }),
        animate('300ms ease-out', style({ opacity: 1 })),
      ]),
      transition(':leave', [animate('300ms', style({ opacity: 0 }))]),
    ]),
  ],
  template: `@for (item of items; track item.id) { <div @row>…</div> }`,
})
```

В приложение подключали `provideAnimationsAsync()` или `provideAnimations()`. В Angular 22 функции пакета (`trigger`, `transition`…) и функции подключения помечены `@deprecated 20.2`: «Use `animate.enter` or `animate.leave` instead. Intent to remove in v23». Новый код пишут на `animate.enter` и `animate.leave` с обычным CSS.
:::
