Строка корзины красиво уезжает, но в конце всё равно случается рывок. Анимация закончилась, Angular удалил элемент, и строки ниже разом подпрыгнули на его высоту. Хорошо бы уходящая строка ещё и схлопывалась по высоте, чтобы соседи поднимались плавно.

## Почему не CSS

Схлопнуть — значит анимировать высоту от «какая есть» до нуля. А «какая есть» в CSS — `height: auto`, и обычный переход от `auto` к `0` браузер не анимирует: ему нужны два числа. (Новое свойство `interpolate-size` это умеет, но есть пока не во всех браузерах.) Число знает только браузер, и только когда строка уже нарисована. Значит, высоту нужно замерить в момент ухода — а это работа для кода.

## Функция вместо класса

У `animate.leave` есть вторая форма — привязка события. Вместо класса Angular вызывает ваш метод:

```html cart/cart-page/cart-page.html {4}
<div
  class="cart-row"
  animate.enter="row-enter"
  (animate.leave)="collapse($event)"
>
```

Метод получает `$event` типа `AnimationCallbackEvent` из `@angular/core`. У него два поля:

- `target` — элемент, который уходит;
- `animationComplete()` — функция «готово, удаляй».

Angular ничего не замеряет и не ждёт событий браузера. Элемент остаётся в DOM, пока вы не вызовете `animationComplete()` — или пока не истечёт страховочный срок (о нём в экспериментах). Как анимировать — ваше дело.

## Анимация из кода: `element.animate`

Анимировать элемент из TypeScript умеет сам браузер: **Web Animations API**. Метод `element.animate(кадры, настройки)` — те же `@keyframes`, только в JavaScript. Он возвращает объект `Animation`, у которого есть событие окончания:

```ts cart/cart-page/cart-page.ts {1,9,10,22}
protected collapse(event: AnimationCallbackEvent) {
  const row = event.target as HTMLElement;
  // Покупатель попросил поменьше движения — удаляем сразу
  if (matchMedia('(prefers-reduced-motion: reduce)').matches) {
    event.animationComplete();
    return;
  }
  // Высоту знает только браузер: замеряем её прямо сейчас
  const { height } = getComputedStyle(row);
  const animation = row.animate(
    [
      { height, opacity: 1 },
      {
        height: '0px',
        paddingBlock: '0px',
        opacity: 0,
        transform: 'translateX(24px)',
      },
    ],
    { duration: 300, easing: 'ease-in' },
  );
  animation.onfinish = () => event.animationComplete();
}
```

Разберём по строкам:

- `event.target` — типа `Element`: Angular не знает, HTML это или SVG. Строка корзины — `<div>`, поэтому `as HTMLElement`;
- `getComputedStyle(row).height` — высота содержимого строки в пикселях, например `"26px"`. Поля (`padding`) в неё не входят — у нас `box-sizing` по умолчанию, `content-box`. Поля мы убираем отдельно — `paddingBlock: '0px'`;
- два кадра: «как сейчас» и «ноль высоты, прозрачная, сдвинута вправо». Браузер сам построит промежуточные;
- `onfinish` — анимация доиграла, и мы говорим Angular: «удаляй».

В коде медиазапрос из прошлого шага проверяют функцией `matchMedia`. CSS здесь не поможет: анимацию запускает не класс, а наш вызов.

Строке нужен ещё `overflow: hidden`. Иначе на последних кадрах, когда высота почти ноль, её содержимое вылезает наружу и наползает на соседей.

::: task
1. В `cart-page.ts` импортируйте `AnimationCallbackEvent` из `@angular/core` и добавьте метод `collapse(event)` — как в примере выше.
2. В `cart-page.html` замените у строки `animate.leave="row-leave"` на `(animate.leave)="collapse($event)"`.
3. В `cart-page.css` в правило `.cart-row` добавьте свойство `overflow: hidden`. Правило `.row-leave` и `@keyframes row-out` больше не нужны — удалите их и уберите `.row-leave` из медиазапроса.
:::

## Что получилось

Нажмите `×`. Строка уезжает, тает и одновременно сжимается по высоте, а строки ниже плавно поднимаются. «Очистить корзину» схлопывает все строки сразу, и только потом появляется «Корзина пуста».

Появление осталось прежним — классом `row-enter`. Две формы можно смешивать: у каждого атрибута своя.

## Эксперименты

**Забыли сказать «готово».** Закомментируйте строку `animation.onfinish = …` и нажмите `×`. Строка схлопнулась — и тут же вернулась целиком, со старым номером. Анимация Web Animations после конца отпускает элемент к его обычным стилям, а удалять строку никто не просил. Примерно через четыре секунды Angular удаляет её сам, без ошибок в консоли. Это страховка на случай, когда `animationComplete()` так и не вызвали: срок задаёт токен `MAX_ANIMATION_TIMEOUT` из `@angular/core`, по умолчанию — 4000 мс. Верните строку.

**`offsetHeight` вместо `getComputedStyle`.** Замените начальный кадр на `{ height: `${row.offsetHeight}px`, opacity: 1 }`. В начале анимации строка сначала **вырастет**: у нас с 34 до 42 пикселей, и только потом начнёт сжиматься. `offsetHeight` считает высоту вместе с полями, а `height` в кадре — без них: поля добавились дважды. Верните `getComputedStyle`.

**Класс из выражения.** У классовой формы тоже есть привязка: `[animate.leave]="выражение"` — Angular возьмёт класс из выражения в момент ухода. Попробуйте вместо функции:

```html
[animate.leave]="$even ? 'row-leave' : 'row-gone'"
```

Правило `.row-leave` и `@keyframes row-out` вы удалили. Чтобы увидеть разницу, верните их на время опыта. Строки с `$even` — первая, третья и так далее по номеру — уезжают с анимацией, остальные (`row-gone` — стилей нет) исчезают сразу. Так выбирают анимацию по данным — например, направление по тому, куда пользователь смахнул строку. Верните `(animate.leave)="collapse($event)"`.

::: tip
`(animate.enter)` тоже бывает функцией: Angular вызовет её, когда элемент появился. Ждать её конца не нужно — элемент уже на месте, поэтому `animationComplete()` у появления ничего не делает. Такая функция пригодится в практикуме главы: обложка будет вылетать из карточки, а откуда — знает только код.
:::

::: deep Под капотом: как Angular ждёт анимацию
Компилятор превращает атрибуты в инструкции:

- `animate.enter="row-enter"` → `ɵɵanimateEnter("row-enter")`;
- `(animate.leave)="collapse($event)"` → `ɵɵanimateLeaveListener(function … { return ctx.collapse($event); })`.

Инструкция не трогает элемент сразу. Она кладёт функцию запуска в список анимаций представления, а Angular выполняет список после отрисовки.

Для класса Angular добавляет его и в следующем кадре (`requestAnimationFrame`) спрашивает у браузера `element.getAnimations()` — или, если там пусто, длительности из `getComputedStyle`. Самая длинная анимация и есть та, которую нужно дождаться. Её `animationend` или `transitionend` снимает класс или разрешает удаление. Не нашёл анимаций — класс снимается, элемент удаляется сразу. Для исчезновения есть ещё таймер на длительность плюс 50 мс — на случай, если событие конца так и не придёт.

Для функции исчезновения Angular ничего не замеряет: он вызывает её и ставит таймер на `MAX_ANIMATION_TIMEOUT`. Что раньше — ваш `animationComplete()` или таймер, — то и удаляет элемент.

Пока элемент уходит, его представление уже отцеплено от шаблона. Поэтому номер уходящей строки не обновился. Удаление родителя (`@if`) ждёт уходящих потомков: Angular собирает обещания их анимаций, в том числе во вложенных блоках, и убирает узел, когда выполнились все (`Promise.allSettled`).
:::
