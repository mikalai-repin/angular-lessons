# Ошибки черновиков

> Справочный архив: **не читать целиком**, искать по слову (`grep -n 'слово' docs/archive/draft-errors.md`).

Что утверждали черновики глав 2–21 и как оказалось на самом деле. Выводы из таблицы — в `docs/authoring-process.md`, раздел 5. Новые находки — строкой в конец таблицы.
