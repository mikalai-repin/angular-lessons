# Ловушки окружения (полный список)

> Справочный архив: **не читать целиком**, искать по слову (`grep -n 'слово' docs/archive/traps.md`).

Самые частые — в `docs/authoring-process.md`, «Главные ловушки». Подводные камни кода платформы — в `architecture.md`, факты об Angular — в `verified-facts.md`. Новые ловушки — сюда.

- **`@angular/compiler-cli` — только ESM**: `require()` не работает, скрипты — `.mjs`. Трансформ: `import { angularJitApplicationTransform } from '@angular/compiler-cli'`.
- **Node 20** не запускает `.ts` напрямую: скрипты в `scripts/` и `tools/` — `.mjs`.
- **zsh**: `$x[?]`, `*.d.ts` без кавычек в аргументах интерпретируются как glob («no matches found»). Для поиска — Python.
- **Не пишите во временные файлы `/tmp`**: используйте папку scratchpad сессии или `tools/e2e/out/` (в `.gitignore`).
- **YAML во frontmatter**: `@`, `{`, `[`, `:` внутри списков — в кавычках.
- **Angular CLI 22 требует Node `^22.22.3 || ^24.15.0 || >=26`**, а по умолчанию в терминале автора Node 20.19 (nvm: есть 22.15, 24.15). Для `ng new` — `nvm use 24.15` или читать шаблоны из `@schematics/angular` (`npm pack @schematics/angular@<версия>`). Важно для главы 20: ученику нужен Node 22+.
- **Эксперименты «сломайте X»**: исключение в конструкторе компонента (вызов несуществующего метода) не даст отрисоваться шаблону — ошибок шаблона (NG0303) уже не будет. Для демонстрации ошибки TypeScript без падения — ошибка только в типах (`let n: number = 'строка'`).
- **Намеренно сломанный старт** (шаг про ошибки): frontmatter `brokenStart: true` — валидатор такой старт не собирает и не проверяет типы.
- **Формат кода уроков = кнопка «Формат».** Настройки — одни на всех: `shared/lesson-prettier.json` (ширина 64, одинарные кавычки, `trailingComma: all`; `.html` — парсер `angular`) читают редактор (`src/editor/monaco.ts`), `prettier.config.mjs` (код уроков; остальной код проекта — ширина 120) и `write_steps` (форматирует полные снимки шагов перед записью — генератору не нужен свой вызов Prettier). Исключения — в `.prettierignore` (сгенерированное, Markdown — Prettier развернул бы списки во frontmatter, — и сломанный старт шага 1.6). Поменяли настройки — `python3 tools/authoring/format-content.py` переформатирует все главы по цепочке (с новыми `baseHash`), затем `npm run validate`, `npx prettier --check .` и `checks/platform.mjs` (проверяет, что «Формат» не меняет файлы уроков). Код в `lesson.md` не переформатируется.
- **Prettier форматирует шаблоны внутри `template:` в `.ts`** (через встроенный парсер Angular). Однострочный шаблон с двумя элементами он переносит некрасиво — пишите многострочный шаблон в обратных кавычках.
- **Puppeteer и Monaco**: пробелы в строках редактора — неразрывные, токены объединяются в один `span` (`" games = httpResource<"`). Чтобы навести мышь на слово, ищите `span` по `includes` и берите координаты через `document.createRange()`.
- **Проверка в настоящем AOT**: `ngc` из `@angular/compiler-cli` работает на Node 20 (в отличие от CLI). Папка с `tsconfig.json` (`experimentalDecorators`, `angularCompilerOptions`), симлинк на `node_modules` проекта, `node node_modules/@angular/compiler-cli/bundles/src/bin/ngc.js -p tsconfig.json` → `out/*.js`.
- **zsh и `echo =====`**: слово из одних `=` zsh разворачивает как путь к команде («==== not found»). Разделители в командах — в кавычках.
- **Проверка шаблонов в AOT строже JIT**: литеральные типы `readonly`-полей, необязательные поля (`oldPrice?`) в арифметике, правила `@let` — JIT молчит. Прогоняйте решения главы через `ngc` со `strictTemplates: true`.
- **Чистое превью `exp.mjs`**: приложение — сама страница, без iframe: `page.click('.card button')`, `page.type('.search', …)`.
- **Шаг со стартом без решения**: в `run-chapter` «Решение» нажимается автоматически, а в своих проверках — нет; стартовый код может не содержать элементов, которые ищет проверка.
- **Генератор главы перезаписывает десятки файлов** — Vite шлёт волну HMR-обновлений, и первая проверка сразу после генерации может упасть по таймауту навигации или без iframe превью. Подождать и повторить.
- **`exp.mjs`**: строки `console.log` самого сценария печатаются сразу, а консоль страницы — в конце; порядок между ними по выводу не восстановить. Нужен порядок — пишите метки в консоль страницы (`page.evaluate(() => console.log(…))`).
- **Prettier раскрывает `@case (…) { Текст }` на три строки** — в тексте урока фрагмент можно дать компактно и предупредить, что после «Формат» он станет длиннее.
- **Ширина ASCII-схем в тексте урока — не больше 46 символов**: панель урока при окне 1440 px показывает около 49 символов моноширинного блока, остальное уходит в горизонтальную прокрутку. Код и вывод консоли могут быть шире.
- **Проверки AOT в scratchpad**: TypeScript 6 требует `rootDir` в `tsconfig.json` папки для `ngc`, если исходники в `src/` (TS5011).
- **В `content/` у шага только изменения.** Пути `content/<глава>/<шаг>/start` и `…/solution` в `run-dir.mjs`, `exp.mjs` и `readDir` дают полный код (`scripts/step-files.mjs`). В Python — `step_dir()` из `tools/authoring/steps.py`; копировать папку шага напрямую (`shutil.copytree`, `cp -r`) нельзя — получите только изменения. Для экспериментов: `npm run step <путь> <папка>`, потом правки в копии.
- **IDE и частичные папки**: открытый `solution/app.ts` может подчёркивать `import … from './core/models'` — файла в этой папке нет, он в старте. Ошибки типов смотрите в `npm run validate`.
- **Проверяйте эксперименты на коде того шага, о котором текст**, а не на решении последнего шага: поведение может зависеть от того, что появилось позже (в главе 5 — `display: inline-flex` хоста из шага 7 скрывал ошибку шага 4).
- **Щелчки в iframe платформы**: `page.mouse.click` по координатам `boundingBox()` элемента внутри iframe в `checks/*` ненадёжен — используйте `elementHandle.click({ offset })`.
- **Отдельный скрипт с `launch()` из `tools/e2e/lib.mjs`, запущенный не как `checks/*.mjs`**, у автора зависал без вывода; диагностику удобнее встроить в проверку главы.
- **Консоль платформы сворачивает одинаковые строки подряд** в одну со счётчиком повторов (`.console-count`). Эксперименты «смотрите, сколько раз напечаталось» описывать через счётчик; в `checks/*` читать `.console-count`. В `exp.mjs` (чистое превью) строки не сворачиваются.
- **Эксперименты с правкой кода — копией шага в scratchpad**: `npm run step <…/шаг/solution> <папка в scratchpad>` (полный код), затем замены с `assert` (скрипт вида `mk.py <имя> <папка> файл 'старое' 'новое' …`) и `exp.mjs` по копии. Так проверены все эксперименты главы 6.
- **Порядок фаз после отрисовки действует между компонентами**: замер в `earlyRead` одного компонента идёт раньше `afterNextRender` без фазы (`mixedReadWrite`) другого. Если элемент открывает/показывает чужой `afterNextRender` (`showModal()`), замеряйте в `read`.
- **`IntersectionObserver` сообщает об изменении видимости**: если после новой порции элемент остаётся видимым, повторного вызова нет (проверено: порция 3, окно 500 × 1400 — застряло на 9). Кнопка «Показать ещё» — запасной путь.
- **Журнал проверок компонентов** — `ng.ɵsetProfiler` (только dev): помощник `cd-log.ts` шага 6.9. Пригодится в следующих главах «под капотом».
- **Копия шага для эксперимента — только в папку `<имя>/solution`** (или `start`): `readStepDir` в `run-dir.mjs`/`exp.mjs` смотрит на родительскую папку и без такой раскладки молча собирает пустое приложение (пустая консоль, пустой текст).
- **Пайпы форматирования пишут неразрывные пробелы**: U+00A0 в `1 990 ₽` и `20 %`, U+202F перед «г.» в датах. В проверках сравнивать после `clean()` из `lib.mjs`.
- **Содержимое `::after` не попадает ни в `textContent`, ни в `innerText`**: точку между частями `.meta` проверка читает через `getComputedStyle(span, '::after').content`. `textContent` у `<dl>` склеивает `dt`/`dd` без пробелов («Итого4 370 ₽») — брать `innerText`.
- **Циклические импорты между файлами превью не поддерживает** («Циклический импорт: … → tab.ts → tabs.ts → tab.ts»), в том числе через динамический `import()`. Родитель-потомок через DI — токен в файле потомка + `useExisting` у родителя (так делает CDK). Эксперимент с NG0200 — два сервиса в одном файле.
- **Журнал `di-log.ts` (шаг 8.9)**: Alt+щелчок в фазе перехвата останавливает событие; строки журнала содержат «NG0201» — `checks/ch08` отфильтровывает их (`openCourse(…, { ignoreConsole })`).
- **Изменили шаг прошлой главы — сломали хеш следующей.** `npm run validate`: «база … изменилась (baseHash …, сейчас …)». `python3 tools/authoring/format-content.py <следующая глава> [и далее по цепочке]` пересоберёт её поверх новой базы: файлы, которые глава не меняет, придут из базы, `baseHash` обновится. Если правка задевает файлы, которые глава сама меняет, — перенесите её в эти файлы руками. Затем `validate`, `run-chapter` и `checks/` главы.
- **Встроенные форматтеры Monaco для HTML и CSS выключены** (`setModeConfiguration` в `monaco.ts`): при двух форматтерах Monaco выбирал встроенный, и «Формат» в `.html` ломал отступы блоков `@if`/`@for`.
- **`localStorage` превью — общий с платформой** (тот же origin, iframe без `sandbox`): сохранённая в главе 9 корзина видна во всех следующих шагах и главах, «Сброс» её не очищает. `openCourse` начинает с `localStorage.clear()`; в `exp.mjs` каждый запуск — чистый профиль Chrome, а «перезапуск» в сценарии — второй `openPreview(page.browser(), compileDir(…))` в том же браузере (тот же `localStorage`). Подделать сохранённые данные для эксперимента — строкой `localStorage.setItem(…)` первой в `main.ts`.
- **Проверка типов фрагментов чужих пакетов** (NgRx в шаге 9.6): `npm pack @ngrx/signals@<версия>` в scratchpad, папка с `node_modules` из симлинков (`@angular` проекта + распакованный пакет) и `preserveSymlinks: true` в `tsconfig.json` — иначе типы пакета не находят `@angular/core` и всё становится `unknown`.
- **Переписали `lesson.md` первого шага главы — потеряли `base`/`baseHash`.** Цепочка молча соберёт старт как полный снимок (в главе 10 у всех шагов пропали файлы глав 1–9: «не найден файл для импорта "../../core/cart-store"»). После ручной правки frontmatter первого шага — `python3 tools/authoring/format-content.py <глава>` не поможет (он читает `base` из того же frontmatter): верните строки `base: …` и `baseHash: …` (`git diff`) и `npm run validate`.
- **`confirm()` в превью и Puppeteer**: щелчок, который открывает `confirm`, блокирует `elementHandle.click()` (таймаут `Input.dispatchMouseEvent`). В `checks/*` — свой обработчик `openCourse(…, { onDialog })` с флагом «принять/отклонить» (как в `ch10`) и щелчок из страницы: `$eval(sel, (el) => setTimeout(() => el.click()))`. По умолчанию `openCourse` диалоги принимает: «Решение» в платформе тоже спрашивает `confirm`.
- **Dev-сервер после правок `src/`** может отвечать `504 (Outdated Optimize Dep)` на все модули — платформа не открывается, проверки падают в начале. Помогает перезапуск `npm run dev`. Чтобы не трогать чужой сервер на 5180, второй — на 5181 со своим кэшем: временный конфиг `{ ...base, cacheDir: 'node_modules/.vite-5181', server: { port: 5181 } }` и `BASE_URL=http://localhost:5181`.
- **Адресная строка превью перезапускает приложение**, `navigate` в `exp.mjs` — нет (pushState + popstate). Номера навигаций (`id`) и журнал «Аналитика: модуль загружен» в текстах зависят от этого.
- **Чистое превью (`exp.mjs`) и `page.click` по ссылке шапки**: щелчок мышью Puppeteer по `routerLink` в шапке не вызывает переход (адрес не меняется, страница не уничтожается) — выводы об отмене запросов оказываются ложными. Щёлкать из страницы: `page.$eval(sel, (el) => el.click())`, и печатать адрес после щелчка.
- **Задержка и ошибки бэкенда в `exp.mjs`**: переменные окружения `LATENCY=1500` и `FAIL_RATE=1`; поменять на ходу — `page.evaluate(() => window.postMessage({ type: 'backend-config', config: { latency, failRate } }, '*'))`. В интерфейсе платформы (`checks/*`) — список `.backend-controls select` и флажок во вкладке «Сеть».
- **Резолвер + страница при задержке**: страница с резолвером появляется через задержку резолвера, а её ресурс грузится ещё столько же — сценарию эксперимента нужно ждать вдвое дольше (при 1500 мс — 3+ с).
- **Учебный бэкенд перехватывает только `fetch`**: `XMLHttpRequest` уходит на dev-сервер и получает HTML платформы — `Http failure during parsing` со статусом 200. В 22.2.1 XHR включают `withXhr()` и `HttpClientModule` (он = `provideHttpClient(withInterceptorsFromDi(), withXhr())`); в старом коде шага 21.7 поэтому `provideHttpClient(withInterceptorsFromDi())`.
- **Данные учебного бэкенда (`games.json`) общие для всех глав**, где есть запросы: демо-магазин шага 1.1 (`checks/preview.mjs`: «Найдено игр: 40») и глава 11+. Первые 12 игр совпадают с локальным `GAMES` глав 2–10 — менять их нельзя.
- **Новая глава не видна на уже запущенном dev-сервере**: после создания `content/<глава>/` платформа на 5180, запущенной раньше, не находила шаги главы (`step-checks`: «No element found for selector: .check-button»). Перезапустите `npm run dev` или поднимите второй сервер на 5181 (см. ловушку про `504`).
- **Подменить `localStorage` в чистом превью** перезагрузкой `page.reload()` нельзя — превью ломается («Загружаем курс…», `collect` падает). Данные — строкой `localStorage.setItem(…)` первой в `main.ts` копии шага.
- **Эксперимент с `localStorage` в `check.ts`**: проверка выполняется в окне превью — `document.defaultView` даёт `window`; запись можно считать подменой `Storage.prototype.setItem`, вопрос гарда — подменой `window.confirm` (верните оба в `finally`).
- **Новая локаль** для пайпов — в двух местах: `LOCALES` в `scripts/copy-vendor.mjs` (файлы в превью) и `localeTypes` в `src/editor/monaco.ts` (типы в редакторе). Иначе код работает, а редактор показывает ошибку TS.

- **Щелчок по координатам в чистом превью 500 × 600**: `page.mouse.click(box.x, …)` по элементу ниже края окна промахивается (фокус остаётся на `BODY`), а выводы о `blur`/«тронуто» оказываются ложными. `elementHandle.click({ offset })` сам прокручивает к элементу.
- **Обычный `<form>` без обработчика `submit`** в чистом превью (`exp.mjs`) перезагружает страницу: сценарий теряет состояние, `collect` падает на `window.__runtimeErrors.splice`. В платформе превью просто запускается заново — это и есть эксперимент 13.3.
- **Страница оформления с пустой корзиной** переадресует на `/cart` (гард): эксперименты и скриншоты формы заказа — с корзиной, подложенной строкой `localStorage.setItem('hod-konem:cart:v2', …)` первой в `main.ts` (так сделан помощник `tools/e2e/out/ch13run.mjs` — в `out/`, не в git; при необходимости перенести в `tools/e2e/`).
- **`check.ts` не видит тело запроса** (`requests` — метод, адрес, статус). Что ушло на сервер, проверяйте по ответу: в 13.10 заказ с 13 играми при остатке 12 должен получить 409, а не 400 «Пустой заказ».
- **Python heredoc с кириллицей** изредка падает `SyntaxError: Non-UTF-8 code` — длинную правку документа надёжнее записать файлом в scratchpad (`# -*- coding: utf-8 -*-`) и запустить.
- **Срок токена шага** (`backend: { tokenTtl }`) действует только на токены, выданные в этом шаге: токен из прошлого шага (час) лежит в `localStorage` и восстанавливается. В текстах и проверках — «выйдите и войдите снова». `exp.mjs`: `TOKEN_TTL=2`. «Вошедшим» проверку удобно начинать вечным токеном: `storage: { 'hod-konem:token': 'token-user' }`.
- **`exp.mjs` и перезапуск с тем же `localStorage`**: второй `openPreview(page.browser(), compileDir(dir), { url, backend })` в сценарии (так проверены вход после перезагрузки и истёкший токен при запуске).
- **Вкладка «Сеть» в `checks/*`**: `page.click('.panel-tab:nth-child(2)')` после ⟳ промахивается — щёлкать из страницы по тексту «Сеть»; после перехода на следующий шаг панель снова «Консоль». Строки `requests()` — с пробелами: `GET /api/me 200 332 мс`.
- **`withViewTransitions` и переадресация из интерцептора при задержке 0**: `AbortError: Transition was skipped…` в консоли (переход посреди анимации). При 300 мс (по умолчанию в платформе) нет — опыты с 401 гонять с `LATENCY=300`.
- **`npm run validate` во время `checks/*`** перезаписывает `.content-check/` — Vite шлёт волну перезагрузок, и проверка в другом процессе падает с таймаутом навигации. Не запускайте их одновременно.
- **zsh: строка `echo "==="`** внутри `;`-цепочки без кавычек вокруг всей команды тоже ломается («== not found») — разделители печатайте словами (`echo "--- шаг"`).
- **LCP и проверка `NgOptimizedImage` зависят от ширины окна**: в сетке одинаковых карточек LCP — та, что на доли пикселя больше. Чистое превью 500 × 600 и окно превью платформы (≈ 508 × 529 при 1600 × 900) дают разные ответы. Проверять `NG02955` нужно при нескольких ширинах (помощник — `openPreview(…, { width, height })` в цикле).
- **Monaco: больше 200 моделей разом** — ошибка страницы «potential listener LEAK detected» (`LanguageService._onDidChange`, порог 200). Новый шаг теперь удаляет модели прошлого (`disposeOtherModels`), но один шаг больше 200 файлов снова упрётся в порог.
- **`@defer` в превью**: каждый блок «грузит» `/chunk-defer-N.js` через учебный бэкенд — в «Сети» и в `requests` у `check.ts` эти записи есть. «Ошибка 500» роняет и чанки; состояние загрузки одно на шаблон — после сбоя `@error` до перезапуска превью. В опыте с ошибкой сначала дождитесь игры, потом включайте флажок.
- **zsh: `set -- $v`** не делит строку на слова — циклы по парам «папка режим» пишите явными вызовами.
- **`grep -E "^(…|…)"` с кириллицей** у автора молча ничего не находил — фильтровать вывод `grep -v "^\[log\]"` или Python.
- **Проверка `check.ts` и `matchMedia`**: «меньше движения» подменяется `win.matchMedia` на время шага проверки (`{ ...original(q), matches: true }`, вернуть в `finally`) — как `confirm` в 13.10.
- **Тесты шага в чистом превью**: `node tools/e2e/run-tests.mjs <шаг/solution> [--with <папка>]` — отчёт как у Vitest; `--with` накладывает файлы папки поверх кода шага (набор образцов — `tools/e2e/fixtures/test-runner/`).
- **Сверка с настоящим `ng test`**: `node tools/e2e/ng-test.mjs <шаг/solution> [--with <папка>] [--browser] [--include=src/app/…spec.ts]`. Первый запуск создаёт проект `ng new` в `tools/e2e/out/cli/hk` (несколько минут) и фиксирует `@angular/*` на версии курса: `ng new` ставит `^22.2.0` — последнюю 22.2.x. Angular CLI 22 и Vitest 5 требуют Node 22.12+/24.15+ — скрипт берёт Node через nvm (`NG_TEST_NODE`, по умолчанию 24.15). `--browser` ставит `@vitest/browser-playwright` и Chromium Playwright (~100 МБ). Частичная переустановка `npm install --save-exact @angular/…@22.2.1` поверх 22.2.3 ломала `node_modules` (пропадал `@angular/common`) — только чистая установка.
- **`ng test` компилирует AOT**: тест с намеренной ошибкой шаблона роняет сборку всех тестов (`NG8001`) — в превью это ошибка одного теста.
- **Дамп генератора (`chNN-gen.py dump <папка>`) и `start`**: `run-tests.mjs`/`run-dir.mjs` читают `<папка>/<шаг>/start` по цепочке — без `lesson.md` шаг считается `previous`, и вместо старта берётся решение соседнего шага. Старт для опыта — копией в `<имя>/solution`.
- **Опыты копиями шага — каждая в своей родительской папке** (`runs/<имя>/step/solution`): соседние папки `readStepDir` собирает как цепочку шагов, и файлы одного опыта «протекают» в другой (в главе 16 в чужой прогон попадал `misc.spec.ts`).
- **Глава с тестами — сверка с `ng test` обязательна**: превью и Vitest расходились в мелочах (цепочка `afterEach`, пустой набор, время ошибок вне тестов, процессы). `node tools/e2e/ng-test.mjs <шаг/solution>` — несколько секунд после первого запуска; `npx ng test --watch=false --reporters=verbose` в `tools/e2e/out/cli/hk` — порядок файлов и тестов.
- **Тесты в превью и `localStorage`**: у прогона тестов своё хранилище в памяти. Опыт, который зависит от сохранённых данных, — `localStorage.setItem` в самом тесте.
- **Пустой `describe` в заготовке** — «No test found in suite» (как в Vitest): заготовка теста без единого `it` красная. Это нормально для старта, но в тексте шага стоит сказать.
- **Объявления типов с `export {}`** превращают `declare module 'x'` в дополнение несуществующего модуля, а `skipLibCheck` прячет ошибку — тип молча становится `any` (так было с первым `shared/vitest.d.ts`). Глобальные объявления — без `import`/`export` на верхнем уровне.
- **Гард с окном и `settle` в `check.ts`**: пока открыто окно подтверждения, навигация ждёт промис гарда — Angular не стабилен, и `click()`/`settle()` проверки висят до тайм-аута 15 с. Щёлкать `элемент.click()` и ждать `setTimeout` окна приложения (`check.ts` 17.8).
- **Адресная строка превью перезапускает и учебный бэкенд**: сохранённая в админке цена после ввода адреса снова прежняя. Опыты «сохранить и открыть снова» — переходами внутри приложения (`navigate` в `exp.mjs`, поиск и ссылка в таблице в `checks/*`).
- **`loggingInterceptor` печатает и ответы из кэша**: строки `GET /api/games/4 → 200` в консоли есть, даже если сервер не спрашивали. Был ли запрос — смотреть во вкладке «Сеть» (в `exp.mjs` — `network`).
- **Правка `content/` во время `checks/*`** (квиз, `lesson.md`) — волна перезагрузок Vite: `ch14-auth.mjs` падал в случайном месте (`frame()` — `undefined`). Длинные проверки — без параллельных правок.
- **Админка в опытах**: вход администратором до запуска — помощник `tools/e2e/out/adm.mjs <папка> <адрес> [сценарий] [роль]` (в `out/`, не в git): первый `openPreview` кладёт `token-admin` в `localStorage`, второй запускает шаг. Мутации практикума 17.8 — `tools/e2e/out/mut17.mjs`.
- **Пакеты не из Angular в превью** (NgRx, глава 18): `copyPackage(scope, name)` в `scripts/copy-vendor.mjs` и glob в `src/editor/monaco.ts` (типы + `package.json` для заглушек подпутей) — оба списка держать одинаковыми. Пакет с той же раскладкой (`fesm2022` + `exports`) подключается одной строкой. Для `ng test` — `tools/e2e/ng-test.mjs` ставит `@ngrx/*` версий из `devDependencies` курса.
- **Ошибки типов в опытах** — копия шага в scratchpad + `tsc` с симлинком `node_modules` проекта (помощник `tc.sh` в scratchpad главы 18: `tsconfig` с `moduleResolution: bundler`, без `*.spec.ts`). Тексты ошибок — из него; Monaco (TS 5.9) пишет так же.
- **`navigate` в `exp.mjs` ждёт затишья** — опыты на гонки и отмену («второй вызов, пока первый не закончился») через щелчки по ссылкам из страницы (`a.click()` по `href`, у ссылок превью префикс `/app`).
- **Журнал в консоли платформы** раскрывает объекты только на два уровня (`{ favorites: { ids: Array(2) } }`) — печатать состояние `JSON.stringify` (мета-редьюсер 18.8, эксперименты с `getState`).
- **`withViewTransitions` и быстрый набор** в поиске: роутер в dev-режиме пишет `AbortError: Transition was skipped` (см. `modern-angular.md`). В `checks/*` эту строку отфильтровывать (`openCourse(…, { ignoreConsole })`), а не подбирать скорость набора — она плавает.
- **Вкладки «Шаблон» и «Дерево» в опытах**: в чистом превью (`exp.mjs`) — `window.postMessage({ type: 'inspect-templates' })` / `'inspect-tree'` и слушатель `message` с `templates`/`tree` (сценарии главы 19 в scratchpad); код для текста урока — тем же Prettier (`babel`, ширина 72), что и вкладка.
- **Новая зависимость платформы (`prettier/plugins/babel`, `zone.js`) — `504 Outdated Optimize Dep`** на сервере 5180, запущенном раньше: проверки — на втором сервере 5181 (см. ловушку про `504`).
- **Настоящая сборка CLI**: `node tools/e2e/ng-build.mjs <шаг> [--jit] [--dev]` (проект `ng-test.mjs`); JIT-сборка магазина падает по бюджету 1 MB, но таблица размеров печатается.
- **TCB шаблона**: `NgtscProgram` из `@angular/compiler-cli` с `_enableTemplateTypeChecker: true` → `program.compiler.getTemplateTypeChecker().getTypeCheckBlock(класс)` (после `loadNgStructureAsync()`).
- **Число `__ngContext__`** после первого `ɵgetLContext`/`ng.getComponent` становится объектом `LContext` — номер читать до отладочных функций.

- **Глава на машине ученика (20): проект для опытов** — `tools/e2e/out/ch20/hod-konem` (свой git, коммит на каждое состояние; `../csr` — `git worktree` до SSR с симлинком `node_modules`). Код шага поверх проекта — `node tools/e2e/cli-overlay.mjs <шаг или папка дампа> <проект> [--keep-app]` (без `--keep-app` удаляет `src/app`, с ним перезаписывает файлы шага — в том числе `app.config.ts`, из которого пропадает `provideClientHydration()`: возвращать руками или `git checkout`). Приложение в Chrome — `node tools/e2e/cli-browse.mjs <адрес> [сценарий] [--js-off]`. Опыт «сломай и собери» — правка, `npx ng build`, `git checkout` (помощник `breakbuild.py` в scratchpad главы 20).
- **Интерактивные команды CLI** (`ng new`, `ng add`) в псевдотерминале Python: спиннер без размеров окна (`TIOCSWINSZ`) пишет сотни мегабайт в секунду; вопрос под спиннером («Would you like to proceed?») не распознаётся по паузе. Вопросы снимать один раз (с пустым `HOME` — вопросы первого запуска), дальше — флаги (`--skip-confirmation`, `--defaults`).
- **Вывод `ng` в текстах** — из проекта с той же версией, что у ученика: `ng new` из CLI 22.2.1 ставит последние 22.2.x. Цифры размеров зависят от кода шага (до и после задания) и версии.
- **SSR и журналы**: код приложения при SSR пишет в терминал сервера (`ng serve` или `server.mjs`), пререндер — в вывод `ng build`. Пререндер ходит к API при сборке: бэкенд должен работать.
- **Puppeteer `console` с ошибкой** отдаёт только первую строку (`message.text()`); полный текст `NG0500` — через `message.args()` и `evaluate((e) => e.message)`.
