- Страница шага грузится лениво (начальный бандл ~2 МБ, 470 КБ gzip), но её чанк вместе с воркерами большой: Monaco + TypeScript Monaco + типы Angular и RxJS. Вырезать ненужные языки Monaco.

- Ошибки TypeScript — на английском (локализации в Monaco нет).
- Нет подсказок и проверки типов в `.html`-шаблонах — этап 5. Подсветка синтаксиса Angular есть (своя грамматика Monarch, `src/editor/angular-html.ts`); в `template:` внутри `.ts` шаблон подсвечивается как обычная строка.
- `XMLHttpRequest` не перехватывается (нужно только если урок покажет `withXhr()`).
- Начальный экран платформы для первого визита (выбор главы) — как в курсе PixiJS, открывается последний шаг.
