## Что держать в голове при обновлении Angular

Некоторые места зависят от внутренностей Angular 22.2 (подробности — в разделах глав 15, 19 и 21 в `archive/roadmap-history.md`):

- `ɵDEFER_BLOCK_DEPENDENCY_INTERCEPTOR` — имитация чанков `@defer` в превью;

- цифры сборок в текстах 19.6 и 20.3, ссылки главы 21 на коммит `fb7711f`.

## Риски

| Риск | Что делаем |
|---|---|
| Ошибки шаблонов в JIT менее понятны, чем в AOT | Отличия называем в тексте; `strictTemplates` в `npm run validate`; этап 5 — по возможности в редакторе |
| Отличия JIT от AOT путают ученика | Называть в тексте явно; глава 20 — перенос в настоящий проект |
| Angular выходит каждые 6 месяцев (23 — около весны 2027) | Версия фиксирована; обновление — отдельной задачей между главами с прогоном всех глав |
| Monaco отстаёт по версии TS | Проверять типы Angular при каждом обновлении |
| NgRx выходит своими версиями (сейчас 22.0.1) | Фиксировать версию точно, как `@angular/*`; при обновлении Angular — проверить совместимость NgRx |
| Экспериментальные API (`debounced`) поменяются | Помечать в тексте, держать список в `modern-angular.md` |
